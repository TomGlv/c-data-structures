# c-data-structures

> Data structures in C: queue (ticket-office simulation), stack (container storage), max-heap (ski stations ranking).

| Folder | Structure | Exercise |
|---|---|---|
| `queue-ticket-office/` | Queue (FIFO, linked list) | Ticket-office / counter simulation |
| `stack-containers/` | Stack (LIFO) | Container storage read from `stock_containers.txt` |
| `max-heap-stations/` | Max-heap | Ski stations loaded from `stations.txt`, ranked by number of slopes |

Dynamic allocation, file parsing (`strtok`, `fscanf`), header/source separation. Visual Studio solutions.
